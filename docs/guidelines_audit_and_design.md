## B. 交互版网站设计

### B1. 整体结构、导航与交互逻辑

**技术选择**：仍放在 GitHub Pages 上，纯静态。前端用原生 JS（ES modules）加 Apache ECharts 5（固定版本，从 cdnjs 加载）。ECharts 自带 Sankey、Treemap、雷达图、关系图、地图、提示框和缩放，一个库就能覆盖全部需求，不需要构建工具，组员也能改。

**数据流**：Python 脚本（`scripts/chNN_*.py`）从原始数据算出每个图的序列，连同单位、来源、指标代码、下载日期、全球/区域排名，一起写进 `site/data/chNN.json`。前端只读这些 JSON，不再做任何计算。这样“自己用原始数据做图”的链条完整可查。PNG 静态图继续生成，供 Markdown 交付文件和不支持脚本的环境使用。

**页面流程**：

1. **开场**：全屏东南亚地图（Natural Earth 公有领域边界），新加坡高亮并带一圈脉冲。因为新加坡在地图上太小，旁边放一个放大插图。悬停显示 4 个关键数字（GDP、人均 GDP PPP、贸易/GDP、FDI 流入/GDP），每个都带全球排名。点击后平滑滚动进入正文，地图收起成顶部的小缩略图。
2. **正文**：单页长滚动，按 Guidelines 顺序排 8 个板块，加上结论和附录。
3. **顶部固定导航**：每个板块一个入口。用 IntersectionObserver 做滚动高亮，当前板块的下划线跟着移动。手机上折叠成横向滑动条。
4. **全局时间控制**：在导航栏下方，可折叠。有两个控件：年份区间（2004 to 2024）和焦点年份。

  js/
    main.js             启动、开场地图、滚动高亮
    state.js            全局状态（年份区间、焦点年份、选中的伙伴/行业/经济体）+ 订阅
    chart.js            makeChart(spec)：统一卡片、提示框（数值+单位+来源）、来源行、数据表、PNG 下载

### B4. 关键交互的实现思路

- **时间滑块联动**：`state.js` 保存 `{range: [2004, 2024], year: 2024}`，各图订阅。时间序列图更新 x 轴范围（ECharts `dataZoom`），快照图（Sankey、Treemap、FDI 条形、雷达）切换到焦点年份。若该指标在焦点年份没有数据，就用不晚于该年的最近一年，并在卡片角上显示“显示 2022 年（最新可得）”，避免看起来像数据错误。
- **Treemap 点击**：ECharts treemap 的 `click` 事件把 `state.sector` 设为所选行业，弹出侧面板；面板里的折线读取该行业的逐年 RCA（四个经济体）。树图支持下钻，面包屑可以返回上一层。
- **Sankey 联动**：点击节点后设置 `state.partner`。Sankey 调低其他连线的透明度，引力散点高亮同一伙伴，伙伴卡片显示份额趋势和 FTA 信息。
- **GVC 关系图**：ECharts `graph`（力导向）。点击节点设置 `state.economy`，下方的参与指数散点和折线用 `dispatchAction('highlight')` 高亮同一经济体。
- **雷达图**：`tooltip.formatter` 读取 JSON 里每个维度的 `rank / n / region_rank / region_n`，显示成“Government effectiveness 95.2 · 全球第 1/205 · 东亚太平洋第 1/34”。
- **滚动叙事**：IntersectionObserver 监听文字段落，进入视口时调用 `chart.dispatchAction` 高亮对应数据点，并切换 `markLine` 注释。
- **悬停提示统一**：所有图都通过 `chart.js` 生成，提示框固定包含数值、单位、来源、指标代码和年份。

### B5. 确保“自己做图 + 来源清楚 + 有排名”的具体做法

1. 每个 JSON 序列都带 `meta: {unit, source, code, retrieved, note}`。`chart.js` 拒绝渲染缺少 `source` 或 `unit` 的图（开发时直接报错）。
2. 来源行自动生成，例如“Source: World Bank WDI (NY.GDP.MKTP.CD), retrieved 12 Nov 2026”。
3. 排名统一在 Python 里用 `rank_table()` 计算（剔除汇总，并列取最好名次，区域 = 世界银行东亚太平洋），写进 JSON。前端只负责显示，不自己算。
4. 只使用 Guidelines 名单里的来源，加上国家统计局（名单允许）。HDI 只有 UNDP 发布，Guidelines 要求展示，所以保留，并在附录里说明。
5. 每张卡片都有“查看数据表”，展开就是图背后的数字。附录列出所有原始文件和生成脚本。
6. 文字里的每个数字都来自 `data/derived/*.json`，构建时可以自动比对。

### B6. 新加坡元素的轻量融入

- 导航左侧放一个 20px 的鱼尾狮线条图标（团队自绘，不用新加坡旅游局的标志），单色，透明度 60%。
- 卡片右上角可选一个极淡的鱼尾狮水印，只放在板块首卡，不放在图表区域内。
- 配色延续现有体系：新加坡用蓝色 `#2a78d6`，同伴用灰色。另选一个低饱和的红色（呼应新加坡国旗）作为强调色，只用在新加坡地图高亮和开场动画里，不用于数据编码，避免和“新加坡 = 蓝色”的规则冲突。
- 开场地图下方用一行小字写 “1°17′N 103°51′E”，作为细节点缀。
